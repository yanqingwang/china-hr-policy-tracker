| 城市/地区 | 政策覆盖的省/市（从标题解析） |

| 新基数(上限/下限)、新比例 | 正文/标题提取；弹性缴存（如东莞模式「比例可在 5%–12% 之间自行选择」）以区间形式呈现并标注「可自行选择」 |

## 方法

### 数据源（`data/sources.yml`）

| 类型 | 来源 | 权威级 |
|---|---|---|
| 官方检索 | gov.cn 政策文件库全文 API（关键词：社保/公积金/工作许可/人才引进/最低工资/个税/就业补贴/劳动合同/残保金） | 5 |
| **70 城发现式采集** | 国家统计局 70 个大中城市逐一检索（每城 3 条：社保缴费基数 / 公积金缴存基数 / 公积金缴存比例），结果**仅收 `*.gov.cn` 域名**——原发布单位优先由域名硬约束保证 | 4 |
| 平台族 | 12333 社保公共服务平台族（si.12333.gov.cn 等）；「掌上 12333 / 全国住房公积金 / 国务院客户端」小程序为登录鉴权封闭生态，不可服务器端抓取，其对应 12333.gov.cn 域名族已纳入扫描 | 4 |
| 频道页 | 人社部 · 国家税务总局（关键词锚定的链接扫描） | 5 |
| 商家解读 | FESCO / HRoot 等（仅作服务商情报，不覆盖官方结论） | 2 |

### 合并取向

- 同题多条记录：保留 `priority` 更高的**原发布单位**记录，解读/转述去重后合并到其附注；
- 社保公积金类在公告标题/正文里明写「由 X 元调整至 Y 元 / 上限 X 下限 Y / 比例由 A% 到 B%」时，才填充新旧数字列；否则对应格留 `—`，链接附在原文列；
- 每条记录都保留原始 URL——机器人不替代原文。

## 订阅：每周一邮件自动送达

打开 `Issues` 页的「📮 订阅 / 退订邮件」模板，填上你的邮箱提交，机器人：

1. **立即对邮箱做了脱敏和加密处理**（AES-256，任何人/维护者都解不开，只有发送 workflow 运行时能解）；
2. issue 标题/正文自动改写为脱敏摘要，**公开页不留明文邮箱**；

4. 退订：同样再次开启 issue，动作改成「退订」即可。

## 双网采集（阿里云 + GitHub CI 合并）

GitHub Actions 与阿里云服务器对城市政府网站的可达性不同（CI 拦部分站、阿里云可达另一部分）。
方案：**阿里云扫一部分推 GitHub，CI 扫另一部分，汇总时合并去重取并集**。

- **阿里云侧**：`deploy/aliyun/install.sh` 一键部署（venv + cron，默认周日 23:00/周一 01:00 UTC 全量扫描）。
  `deploy/aliyun/run_aliyun.sh` 产出 `data/discovery-aliyun.json` 后：
  - 服务器能访问 GitHub → 配 `GH_PAT` 环境变量，自动推到 `aliyun-data` 分支；
  - 访问不了 GitHub（常见）→ 写入 web 目录，把文件公网 URL 设为仓库 Secret `ALIYUN_DATA_URL`。
- **CI 侧**：weekly.yml assemble 先 `curl` 拉取阿里云数据（Secret 未配则跳过），与 4 分片采集合并；
  `merge.py` 按 uid/同题去重（跨年版本进沿革），覆盖统计取并集。
- 覆盖数 = 两网可达城市之和，周报「覆盖统计」如实反映。
